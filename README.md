# DAA Assignment 1

Assignment 1 for Design and Analysis of Algorithms.

The project implements three Divide and Conquer algorithms in Java:

- MergeSort
- QuickSort
- QuickSelect

The project also contains performance metrics, benchmark tests and JUnit 5 tests.

## Requirements

- Java 17
- Maven
- IntelliJ IDEA
